# goit-js-hw-03

JavaScript Arrays — Homework 3

## Tasks

- **Task 1** — `slugify()`: converts a string into a URL-friendly slug
- **Task 2** — `makeArray()`: merges two arrays and trims to a max length
- **Task 3** — `filterArray()`: returns numbers greater than a given value

## How to run

Open `index.html` in a browser and check the console (`F12` → Console).

## Technologies

Vanilla JavaScript (ES6 modules)
